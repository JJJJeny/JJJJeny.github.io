# Jenny Yang Portfolio

One-page product management portfolio for GitHub Pages.

## Publish

Create the public GitHub repository `JJJJeny.github.io`, push the `main` branch,
and enable GitHub Pages from the repository root. The site will be available at:

https://jjjjeny.github.io

## Edit the site

- Edit visible text and links in `index.html`.
- Edit colors, spacing, and image sizing in `styles.css`.
- Replace an image in `assets/` while keeping the same filename, or update its
  filename in `index.html`.
- The original YC icon is `assets/yc-icon.webp`.

Open `index.html` in a browser to review simple edits before publishing.
